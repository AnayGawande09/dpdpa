How the Analyzer Works

Statutory validation pipeline lifecycle

  1. Detection
    Regex patterns, spaCy NER, and column-name heuristics scan every field for likely PII.
  2. Classification
    Each detection is mapped to a DPDP taxonomy category.
  3. Rule Engine
    Detected PII and your declared context are evaluated against a versioned set of DPDP Act 2023 / DPDP Rules 2025 rules.
  4. Gap Detection
    Every failed rule becomes a finding — affected fields, missing control, recommended action.
  5. Risk Score
    Findings and PII sensitivity combine into an explainable 0–100 score with a fully traceable breakdown.
