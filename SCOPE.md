# Scope & Guardrails — DPDP Compliance Analyzer

These constraints are load-bearing for every phase of this build. If a later
change would violate one of these, stop and flag it instead of building it in
silently.

1. **This is a BATCH pipeline (upload a file, run a scan) — NOT live real-time
   monitoring.** There is no streaming ingestion, no live database/API
   connector, and no continuous background watcher. A user uploads a dataset
   and triggers a scan; that scan runs once and produces a result.

2. **No custom-trained ML PII model.** PII detection uses regex patterns,
   spaCy's off-the-shelf `en_core_web_sm` NER model, and column-name
   heuristics only. Nothing in this project is fine-tuned or trained on our
   own data.

3. **Risk scoring is an explainable WEIGHTED formula, never a black-box
   model.** Every point in a risk score must be traceable to a named factor
   with a documented weight — no opaque ML-based scoring.

4. **Every compliance rule lives in `/app/rules/rules.json` as structured
   data — never hardcoded in Python conditionals.** The rule evaluator is
   generic: it reads rules from JSON and dispatches to registered condition
   functions. Adding or removing a rule must never require changing the
   evaluator's control flow.

5. **Every finding must cite the `rule_id` and evidence field that triggered
   it.** No finding may be generated without a traceable rule and evidence
   source.

6. **All UI/report copy says "potential compliance gaps" / "assessment
   findings," never definitive legal claims.** This tool produces an
   automated assessment against a configurable rule set — it does not give
   legal advice and does not make a definitive compliance determination.
   This applies to dashboard copy, PDF report copy, and any explanatory text
   generated by the pipeline.

## Out of scope (scope-creep flags)

If any future phase starts proposing real-time log streaming, live DB/API
connectors, a custom-trained PII/NER model, or an ML-based (non-weighted)
risk score, that is scope creep beyond this project's timeframe. Point back
to this file and stop.
